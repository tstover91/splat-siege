# Splat Siege

A side-view paint artillery prototype made in Godot.

**Play:** https://tstover91.github.io/splat-siege/

Take turns purchasing your complete arsenal, then manually aim paint weapons at the opposing fort. Both inventories remain visible. The player with the highest coverage wins after all supplies are used.

This repository contains the exported browser game. The editable Godot source stays in the local development project.

## Controls

- Buy items from the shop, then finish purchasing.
- Choose an inventory item.
- Drag up for a higher arc and right for more power; release to fire.
- Or adjust the sliders and press FIRE.
- Shields and cleaning each use a turn.
